# Bài Tập: Tạo Form Survey Khảo Sát Khách Hàng (Customer Survey Form)

Bài tập thực hành xây dựng biểu mẫu khảo sát ý kiến khách hàng chuẩn:
- Họ và tên: First Name & Last Name
- Email khách hàng
- Bảng ma trận Radio button đánh giá mức độ hài lòng theo 5 mức độ và 3 tiêu chí (Chất lượng sản phẩm, Thái độ phục vụ, Tốc độ phản hồi)
- Trường góp ý kiến: `<textarea>`
- Nút Gửi khảo sát (`<button type="submit">`)
- Giao diện định dạng đẹp mắt, gọn gàng với `style.css`.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
